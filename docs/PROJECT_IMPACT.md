# 项目影响与维护证据

## 面向的问题

本项目服务于希望用中文系统学习古兰经阿拉伯语、同时需要离线使用和本地隐私保护的学习者。现有资料往往把词表、经文、发音和复习计划拆散，或依赖持续联网。

## 项目的差异

- 词条与完整经文语境关联；
- 主动回忆、听辨、辨形和间隔复习形成统一学习路径；
- Web/PWA 与 Android 共用学习界面；
- 学习状态和录音本地保存；
- 将代码许可证与教材、翻译、诵读音频的权利分开治理；
- 对经文显示范围和播放范围的一致性提出明确发布门槛。

## 当前阶段

项目于 2026-07-26 首次公开，目前处于早期社区阶段。尚无足够公开采用数据，因此不声称已有广泛用户或生态影响。当前可核验成果包括：

- 公开 GPL-3.0-only 源码；
- Web/PWA 和 Android 两个交付面；
- 自动化仓库边界检查；
- 完整的内容再分发边界；
- 明确的路线图、维护职责和贡献入口；
- 可复现的首个社区源码 Release。

## 持续维护工作

主要维护者承担真实的产品和工程维护工作，包括学习流程设计、缺陷复现、Android 构建、真机验证、数据边界审查、发布管理、Issue 分类和社区文档。

## 为什么适合 Codex for Open Source

项目的维护负担不仅是编写界面，还包括大量跨文件审查、数据契约验证、版本发布、Issue 分类、回归测试和内容来源治理。Codex 可用于：

- 审核 Pull Request 和生成有证据的回归清单；
- 自动验证内容包字段和引用完整性；
- 检查经文显示范围与音频元数据范围；
- 维护 Android/Web 双端的一致性；
- 生成发布变更摘要和维护者文档；
- 辅助安全扫描，但不替代人工内容与发音复核。

## 诚实边界

项目是新公开的仓库，尚未建立采用量、贡献者数量或长期发布历史。申请支持的理由是其清晰的公共教育用途、独特语言服务范围、维护复杂度和可审计治理方向，而不是虚构的流行度。
