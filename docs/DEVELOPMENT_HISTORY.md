## 公开源码阶段

- `v0.1.0-community`（2026-07-26）：首次公开程序代码、治理文件和内容边界；
- `v0.2.0-community`（2026-08-01）：增加可运行的七日无音频演示包、动态内容数量、完整课程词汇展示、来源许可和自动内容验证。

## 如何理解这些证据

内部迭代说明项目经历过持续的产品和工程维护，但不能替代公开采用数据。仓库不会把内部构建数描述成 GitHub 发布数，也不会虚构用户、星标、贡献者或社会覆盖人数。公开影响将以可核验的 Issue、Pull Request、Release、下载和真实反馈逐步积累。
