# 发布检查表

## 源码发布

- [ ] 工作树干净，目标提交已推送；
- [ ] JavaScript 语法检查通过；
- [ ] 公开内容验证脚本通过，并确认音频文件数为 0；
- [ ] Android Debug 构建通过；
- [ ] 不含密钥、个人数据、受限媒体和大文件；
- [ ] README、CHANGELOG 和版本号一致；
- [ ] GitHub Actions 成功；
- [ ] 标签指向预期提交。

## APK 发布附加门槛

- [ ] 所有随包数据和媒体均有明确再分发权利；
- [ ] 经文显示范围与音频范围一致；
- [ ] 用户界面不含内部审核或开发提示；
- [ ] 使用 release keystore 签名；
- [ ] 完成安装、升级、离线、权限和关键交互真机测试；
- [ ] 记录 APK 文件大小与 SHA-256；
- [ ] Release 中附许可证与第三方通知。

任何一项未满足，都不发布 APK。
