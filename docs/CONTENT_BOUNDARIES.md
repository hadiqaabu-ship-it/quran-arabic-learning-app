# 内容与发布边界

## 可以公开

- Web/PWA 界面代码；
- Android 离线容器代码；
- 自己编写的文档、测试和数据结构说明；
- 明确由贡献者拥有并按兼容许可证提供的内容。

## 当前不公开

| 内容 | 原因 | 处理方式 |
|---|---|---|
| ChatGPT 朗读音频 | 服务条款限制独立音频再分发 | 重新录制或取得书面授权 |
| Microsoft 神经语音音频 | 再分发范围尚未完成核验 | 暂不提交 |
| Quran.com / Quran Foundation 诵读音频 | 未确认可随 APK/仓库再分发 | 使用获授权来源或取得许可 |
| 第三方教材和 PDF | 可能包含受版权保护的编排与文本 | 只发布自有原创课程 |
| 完整生产课程数据 | 混合了多种来源 | 逐项建立来源、版本和许可证清单 |
| APK | 当前内容权利和正式签名未完成 | 完成版权审查与 release 签名后再发布 |

## 发布门槛

公开 APK 或 GitHub Release 前必须同时满足：

1. 所有随包内容都有明确再分发权利；
2. 音频和页面显示的经文范围一致；
3. 不含内部审核或开发提示；
4. 使用 release keystore 签名；
5. 完成真机交互、安装升级、离线和权限测试；
6. 保存版本号、SHA-256 和测试记录。
