## 当前不公开

| 内容 | 原因 | 处理方式 |
|---|---|---|
| 任何诵读或单词音频 | 本次发布明确采用零音频边界 | 取得逐项再分发许可后另行评审 |
| ChatGPT、Microsoft 等朗读导出 | 不能仅凭可播放推断可独立再分发 | 取得书面许可或制作权利清晰的自有录音 |
| 第三方现代中文译文 | 现代译文可能受版权保护 | 仅采用权利明确的译本或原创学习释义 |
| 第三方教材和 PDF | 可能包含受保护的编排与文本 | 只发布自有原创课程或获授权材料 |
| 完整生产课程数据 | 混合来源仍需逐项审查 | 建立来源、版本和许可证清单后分批开放 |
| APK、签名材料、设备日志 | 正式签名和发布测试尚未完成 | 达到移动发布门槛后单独发布 |

## 为什么古兰经内容也需要版权审查

古兰经阿拉伯语原文的年代，不会自动消除现代数字版本编排、译文、诵读表演或录音制品的权利。网页“可以播放”也不等于“可以下载、打包进 APK 并在 GitHub 再分发”。因此本仓库按每一类内容分别核验，而不是笼统地判断为“有版权”或“无版权”。

## 音频发布门槛

未来任何音频进入仓库或 Release 前，必须同时满足：

1. 记录权利人、来源、具体许可证和获取日期；
2. 许可证明确允许 GitHub 与离线安装包再分发；
3. 音频范围与页面显示的完整经文范围一致；
4. 建立词条、实际发音内容和文件的一对一语义核验；
5. 完成真机播放、离线、暂停、循环和异常恢复测试；
6. 保存文件 SHA-256、版本号和人工复核记录。

当前版本不满足也不尝试满足该门槛，因此音频文件数固定为 0。
